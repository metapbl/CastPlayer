## 1. 범위
- 수준과 이유: 기본. 혼자 쓰는 Windows 데스크톱 도구이고 계정·비밀값이 없으며 인터넷에 노출하지 않는다. 같은 네트워크에 여는 미디어 서버만 따로 규칙을 둔다 (§5) [U] (D072)
- 서비스 지역·적용 규제: 해당 없음 (개인 오픈소스, 정보를 수집하거나 서버로 보내지 않음) [U] (D072)
- 이 정책이 다루지 않는 것: 비밀번호 저장·인증·권한·업로드·암호화 키 (계정과 서버가 없음), 화면 모양 [AI] (D072)

## 2. 구성요소와 신뢰 경계
| 구성요소 | 배포 위치 | 인터넷 노출 | 들어오는 입력 | 이 경계의 통제 |
|---|---|---|---|---|
| GUI (`main.py`, `ui/`) | 사용자 PC | 아니요 | 사용자 조작, 사용자가 연 영상·자막 파일 | 파일은 신뢰하지 않는 입력으로 처리 (§5 파일) [X] |
| 미디어 서버 (`core/media_server.py`) | 사용자 PC, `0.0.0.0:8765` | 아니요 (같은 네트워크만, 방화벽 "개인 네트워크" 허용) | 같은 네트워크의 HTTP 요청 (TV 기본 수신 앱) | GET·HEAD만, 무작위 토큰 경로만 응답, 나머지 404 (§5 미디어 서버) [X] |
| TV 제어 (`core/cast_manager.py`, pychromecast) | 사용자 PC → TV 8009 | 아니요 | TV가 보내는 상태 메시지 | TLS 연결이지만 인증서 확인 없음 (라이브러리 동작, 바꿀 수 없음). 같은 네트워크 전제로 받아들임 [X] |
| ffmpeg·ffprobe (`core/probe.py`·`keyframes.py`·`subtitles.py`·`transcoder.py`) | 사용자 PC, 하위 프로세스 | 아니요 | 사용자가 연 영상 파일 | 인자 목록으로만 실행, 셸 안 씀 [X] |

## 4. 클라이언트 규칙
- 비밀값(API 키 등)을 코드·빌드에 넣지 않는다. 지금 없음 [X] (D072)
- 파일 (V5): 영상·자막은 신뢰하지 않는 입력이다. ffmpeg·ffprobe는 인자 목록으로만 부르고 `shell=True`를 쓰지 않는다. 자막은 인코딩을 판별하지 못해도 대체 문자로 읽어 오류 없이 연다 (F5-5), 마크업은 `<i>`·`<b>`·`<u>`만 남긴다 [X] (D072)
- 문서·커밋·코드 주석·공유 로그에 실제 IP·기기 이름·사용자 경로·영상 파일 이름을 쓰지 않는다 [U] (D041, D072)

## 5. 서버 규칙 (미디어 서버)
- 인증: 없음. 대신 경로마다 `secrets.token_urlsafe(16)`(128비트) 무작위 토큰을 쓴다. 토큰은 재생 요청에 담아 TV에만 알린다 [X] (D001, D072)
- 권한 (누가 무엇을): 같은 네트워크에서 토큰을 아는 쪽만 그 파일을 받는다. 등록한 파일만 보내고, 정지·새 파일·종료·재연결 포기 때 등록을 지운다 (D029의 끊김 중 유지 규칙은 그대로) [X] (D072)
- 입력 검증: GET·HEAD(와 CORS OPTIONS)만 처리, 등록 안 된 경로는 404. Range 헤더는 형식을 확인하고 범위 밖이면 거부 [X] (D072)
- CORS: `*` (기본 수신 앱이 다른 출처에서 받으므로 필요). 읽기만 하므로 상태를 바꾸는 요청이 없다 [X] (D001)
- 오류·로그: 오류는 상태줄에 일반 문구로, 자세한 내용은 로그(기본 꺼짐)에만 [X] (D070)
- 이 동작(토큰 경로, 읽기 전용, 재생 중만 등록)을 바꾸는 변경은 PRD 변경 절차로 한다 [AI] (D072)

## 7. 비밀값
- 없음. 생기면 저장소에 커밋하지 않고 이 표에 적는다. `.claude/settings.json`이 `.env`·`*.pem`·`*.key` 읽기를 막는다 [X] (D072, metarche U2)

## 8. 의존성
- lock 파일: `requirements.lock.txt` (`.venv`에서 `pip freeze`로 만들고 커밋, 라이브러리를 바꿀 때 다시 만든다) [U] (D072)
- 취약점 검사 명령: 공개 배포(zip) 전에 `.venv\Scripts\pip-audit -r requirements.lock.txt`. `pip-audit` 설치는 실행 전 확인 (D048) [U] (D072)
- ffmpeg는 동봉하지 않으므로 사용자가 설치한 버전을 따른다 [X] (D042)
