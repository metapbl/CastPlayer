# pyright 오류 정리 (O107)
상태: active | 시작: 2026-10-28 | 근거: D063, D068, O107

목표: `pyright` 오류 0개로 만들고, 편집 때 check 훅이 ruff 다음에 pyright를 돌린다. 동작은 바꾸지 않는다.
구조:
- `pyrightconfig.json` (새 파일) — 검사 범위(`main.py`, `core`, `ui`, `tools`)와 `.venv` 지정. 훅·수동 실행이 같은 설정을 쓴다
- `core/*.py`, `ui/main_window.py` — Optional 좁히기, pychromecast import 경로, stub이 모르는 PySide6 호출
- `tools/cast_test.py` — 가짜 객체(SimpleNamespace·object) 대입 오류, Optional 좁히기
- `.claude/hooks/check.ps1` — `.py` 검사에 pyright 추가
전역 제약:
- 타입 때문에 동작을 바꾸지 않는다. 좁히기는 이미 보장된 곳에만 쓴다 (지역 변수에 담기 > `assert x is not None` > 줄 단위 `# pyright: ignore[규칙]` 순)
- `# pyright: ignore`는 stub이 틀린 곳에만 쓰고 이유를 한 줄 남긴다
- 작업마다 `--selftest` 전부 통과해야 커밋한다
- pyright는 전역 npm 설치본(1.1.414)을 쓴다. venv에 넣으려면 `pip install`이 필요하므로 묻는다 (D048)

현재 (2026-10-28, pyright 1.1.414): 71개 — cast_test 39, cast_manager 14, main_window 7, keyframes·media_server·player·subtitles·transcoder 각 2, planner 1
